# 实机验收清单

仓库没有构建和自动化测试，所有结论都靠在游戏里看。每一项只记“通过 / 不通过 + 现象”，
不通过时附内容日志和截图，不要先猜原因。

进入方式：手持物品对方块单次使用。木棍 `assembly_demo`，烈焰棒 `forge_demo`，红石灯 `redstone_lamp_demo` 与 `lamp_states`。

## 1. 能不能起来

- [ ] 加载世界后内容日志没有 BP/RP 报错（尤其是 `ponder:section_block`、`ponder:text/frame/line/icon` 的实体定义和 `server_form.json`）。
- [ ] 手持木棍使用方块，出现“正在准备展示区”，随后看到远端的场景，玩家本体没有被传送。
- [ ] 点关闭、Esc、受伤都能退出，镜头、HUD、输入恢复。

## 2. 方块滑入动画（最需要验证的新机制）

对应脚本 `SectionAnimator`，客户端实体 `ponder:section_block`。

- [ ] 底板出现时有从上方滑入加放大的动画，结束后换成真实方块没有闪一下。
- [ ] `hideSection` 有滑出缩小的动画。
- [ ] 动画实体本身不抖动，方块位置与最终真实方块重合。
- [ ] 手持方块的朝向和位置对不对：偏了就把截图发给我，我调 `animation.ponder.section` 里的 `v.cal_*` 校准量（参考 LordPhysics 的 `cal_*`）。
- [ ] `playanimation` 命令带 `v.s=…;v.dur=…` 是否生效。无效时看内容日志里的 `[Ponder] playanimation`。

## 3. 标注

- [ ] 文字、说明框、指示线是否面向相机，透视是否正常。
- [ ] 文字窗口前后各 5 tick 淡入淡出。
- [ ] 轮廓框、值输入框（首 tick 是点，随后膨胀）。
- [ ] 操作提示（`showControls`）的图标、物品、潜行前缀，以及从 `pointing` 方向滑入。
- [ ] 字距和换行：目前仍是估算宽度，不准时告诉我具体哪一行。

## 4. UI

- [ ] 头部：左上角标题、图标框、渐变拖尾的位置和大小，对照 Java（拖尾起点 55,19；图标框视觉约 38×38；图标 32×32）。目前仍沿用基线 24×24 / 40×40。
- [ ] 侧栏：x=31、纵向间距 30；悬停提示条向右展开，文字 `#ddeeff`。
- [ ] 底部按钮：上一个、关闭、下一个、重播、返回、舒适阅读都能点；首个场景上一个禁用。
- [ ] 进度条：分段走、点击关键帧刻度跳转；刻度位置按真实时间比例摆放（文本传值）。刻度全部堆在左端说明 `%.3s` 嵌套表达式在你的版本上不成立。
- [ ] 说明气泡出现的延迟和引线展开。
- [ ] 播完后“下一个场景”提示在约 2.5 秒后出现，下一个按钮脉冲。
- [ ] 索引页：物品索引、标签索引、卡片翻页、返回。

## 5. 时间轴

- [ ] 跳转关键帧后，方块、标注、镜头回到该时刻的脚本状态。
- [ ] 舒适阅读：文字窗口显示时每 3 tick 才走 1 tick。
- [ ] 重播从头开始，不重复生成实体和粒子。

## 6. 结构文件（等你提供 `.mcstructure` 后）

- [ ] `getPackStructureIds()` 的实际输出（发给我）。
- [ ] `loadSchematic("name")` 读出的尺寸和方块与结构方块里看到的一致。
- [ ] 带状态的方块（朝向、半砖上下）是否保留。

## 7. 多人、维度、恢复

- [ ] 三个维度各进入一次。
- [ ] 两名玩家同时使用，互不影响。
- [ ] 退出后展示区被清理，常加载区被释放；中途断线或重载脚本后能恢复。
