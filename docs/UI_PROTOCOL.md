# 表单协议

脚本用一个 `ActionFormData` 驱动整个界面，JSON UI 把按钮文本当作数据读取。
这份文档是脚本（`PonderForm.js`）和 `src/RP/ui/server_form.json` 之间的约定，两边必须同步修改。

## 标题

`§0§r§1§r` 开头表示这是 Ponder 表单，其余表单不受影响。后面依次是：

| 段 | 含义 |
| --- | --- |
| `\|scene\|` / `\|index\|` | 场景页 / 索引页 |
| 进度档 `§4§r§K§r` | 进度条分成 K 段，K ∈ {4, 8, 12, 16, 24}，选对应的填充控件组 |
| 进度值 | 当前停在第几段（0..K），十进制 |
| `§6§r` | 本次打开时进度条从上一段动画走到当前段 |
| `§7§r` | 反向动画（回退关键帧） |
| `§9§r§0/1/2§r` | 说明气泡所在槽位（上/中/下） |

## 按钮槽

槽位序号固定，见 `enums/PonderConfig.js` 的 `SLOTS`。按钮文本前缀：

| 前缀 | 含义 |
| --- | --- |
| `§0§r§0§r` | 隐藏 |
| `§8§r§8§r` | 禁用 |
| `§a§r§a§r` | 高亮（当前所在、播放完毕提示） |

## 进度条为什么分档

JSON UI 的动画时长是常量，脚本不能传入。所以进度条预置若干档，每档把条分成等长的段，
每段一个 0.2 秒的尺寸动画。脚本按场景关键帧数量选最接近的档，每次切换关键帧时重新打开表单。
段内的真实时长不会精确反映，只表示“第几段”。

## 与 Java 的差异

| Java | 这里 |
| --- | --- |
| 进度条每 tick 平滑逼近 | 按段走，段间 0.2 秒 |
| 点击进度条任意位置跳转 | 每个关键帧一个透明按钮 |
| 快捷键 Q/A/D/S/E | 不做，只保留点击和返回键 |
| 屏幕缩放过渡 | 沿用基线的透明度加位移 |
| Identify 模式 | 不做（依赖鼠标射线） |
