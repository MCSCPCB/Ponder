# 表单协议

脚本用一个 `ActionFormData` 驱动整个界面，JSON UI 把按钮文本当作数据读取。
这份文档是 `PonderForm.js` 和 `src/RP/ui/server_form.json` 之间的约定，两边必须同步修改。

## 刷新时机

表单只在玩家点击按钮后由脚本重建并重新打开。播放过程中不主动重开，所以进度条和说明气泡
在两次点击之间不会自己更新，段内动画是表单打开时由 JSON UI 本地播放的。
说明文字不在表单里：它是世界里的文字实体，指示线要指向场景中的具体位置，表单拿不到这个坐标。

## 标题

`§0§r§1§r` 开头表示这是 Ponder 表单，其余表单不受影响。之后：

| 段 | 含义 |
| --- | --- |
| `\|scene\|` / `\|index\|` | 场景页 / 索引页 |
| `§4§r§X§r` | 进度条档位，X ∈ a b c d e，对应 4 8 12 16 24 段（`TIER_CODES`） |
| 段号 + `\|` | 进度条停在第几段（0..档位），后面的 `\|` 避免 1 与 12 混淆 |
| `§6§r` / `§7§r` | 本次打开时进度条从上一段向前 / 向后动画 |
| `§5§r` | 场景已播完，显示“下一个场景”提示 |

## 按钮槽

序号固定，定义在 `enums/PonderConfig.js` 的 `SLOTS`，UI 里通过 `collection_index` 读取。

| 序号 | 用途 |
| --- | --- |
| 0 1 2 3 4 5 | 上一个、关闭、下一个、重播、舒适阅读、返回 |
| 6 | 标题与图标（文本是场景标题，图标是场景图标） |
| 7 | “下一个场景”提示内容 |
| 8–13 | 侧栏标签，最多 6 个 |
| 14–37 | 关键帧刻度按钮，最多 24 个 |
| 38–45 | 索引页卡片，每页 8 张 |
| 46 47 | 索引页上一页、下一页 |
| 48 49 | 物品索引、标签索引入口 |

按钮文本前缀：`§0§r§0§r` 隐藏，`§8§r§8§r` 禁用，`§a§r§a§r` 高亮。

## 关键帧刻度的位置

刻度按钮的文本是 `§0§r§2§r` + 三位像素位置 + `^` + 显示文字，例如 `§0§r§2§r042^跳转 3`。
`ponder_keyframe_button` 的 `property_bag` 预置 `#x000`…`#x224` 共 225 个键，各对应一个偏移值；
绑定取文本的前三位拼成 `#xNNN` 写入 `#offset`。这是沿用 `_sample/成就ui模板` 里的文本选键做法，
不涉及字符串转数值。

## 进度条为什么分档

JSON UI 的动画时长是常量，脚本不能传入。进度条预置 4/8/12/16/24 五档，每档把条分成等长的段，
每段一个 0.2 秒的尺寸动画。脚本按关键帧数量选能容纳的最小档。

## 与 Java 的差异

| Java | 这里 |
| --- | --- |
| 进度条每 tick 平滑逼近 | 按段走，段间 0.2 秒 |
| 点击进度条任意位置跳转 | 每个关键帧一个透明按钮 |
| 快捷键 Q/A/D/S/E | 不做 |
| 屏幕缩放过渡 | 淡入加位移 |
| Identify 模式 | 不做 |
