## 已确认方案

- 使用自由相机与常加载区展示真实世界方块和实体，替换结构方块 JSON UI 渲染层。
- 不拘泥于现有实现，可以重构；移除 `3d_structure_renderer` 与实体伪方块展示，不复刻方块平滑移动。
- 展示区位于玩家当前维度远方的安全空置区域，每名玩家独立分配，避免占用与多人冲突。
- 外壳使用黑色混凝土，替换此前约定的屏障外壳；内部默认填充最高亮度光源方块，明确需要空气的位置保留空气。
- 通过常规自由相机构图和脚本运镜模拟整体旋转。用户最新确认其所指的原生正交视角与鼠标互动是官方 camera 配置中的能力，但依赖玩家本体，不能用于本项目；这两项接入调查已关闭，不再索例或改变玩家原地架构来迁就它们。
- 不做原生正交接入、鼠标拖拽旋转、世界场景悬停识别及拾取，不保留无功能的识别入口；普通 JSON UI 按钮的点击、悬停及按钮驱动的关键帧跳转仍保留。不承诺常规自由相机与 Java 正交画面几何等价。
- 指示线、说明框和文字统一作为世界中的实体标注，使用面向相机、透视材质等能力。
- 世界实体文字不做设备屏幕尺寸或 GUI 缩放联动适配；通过世界空间布局和相机构图容纳结构、文字、说明框及指示线。屏幕 JSON UI 自身的设备适配仍保留。
- 用户已验证远距离自由相机下实体标注和文字能够稳定显示，不重复质疑或要求重做这项验证。
- 保留 JSON UI 与现有表单交互：点击按钮后由脚本处理，再重建表单同步状态。
- 表单打开期间的视觉变化用界面本地绑定和预设动画，不要求脚本实时修改已打开的表单。
- DDUI 尚不满足样式要求，当前不改用 DDUI。
- 物品图标沿用脚本或场景配置的贴图路径（`iconPath`）；用户已确认 `item_id_aux` 数值映射会受 addon 影响，不再调查或采用命名空间 ID 到 `item_id_aux` 的转换方案。
- 只控制教学时间轴的推进、暂停、继续、回退、重播；不暂停、倒退或快进红石、水流、生物 AI 等原生世界模拟。
- 玩家受伤害且正常结算后自动关闭思索，恢复相机、HUD 和输入；不添加免伤。
- 入口暂沿用手持已注册物品右键使用；双击潜行只是曾提议的方案，未被采用。
- 用户确认目标环境可在依赖版本填 `alpha`、不开启实验性 API 且兼容成就；按此适配，不再只限制到 `2.10.0`。这属于用户已验证的环境约束，不扩大成所有版本的官方保证。
- UI 样式逐项对齐 Java sample，具体尺寸、状态、颜色、布局及动画目标见待办。
